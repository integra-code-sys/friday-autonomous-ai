Projetada para Qualquer Cenário de Hardware e Nuvem

Nem todo usuário possui múltiplas câmeras ou GPU dedicada. A edição comercial da Integra Code se adapta automaticamente ao seu equipamento.

📷 0, 1, 2 ou 3+ Câmeras PTZ

No modo 0 câmeras (Desktop), analisa apenas a tela. Com 1 câmera (Notebook), unifica rosto, gestos e objetos na mão. Com 2 ou 3+ câmeras, separa ambiente, porta e controle PTZ ONVIF.

☁️ IA Local (Ollama) ou Cloud (BYOK)

Rode 100% offline com Ollama (Qwen3-VL / Llama) ou conecte sua própria chave de API do Google Gemini 2.5, Anthropic Claude 3.5 ou OpenAI GPT-4o com fallback automático.

🧠 Memória e Aprendizado do Zero

Banco de dados Zero-State limpo de fábrica. Aprende fatos sobre o usuário, grava receitas episódicas de tarefas bem-sucedidas e extrai lições de autocrítica para nunca repetir erros.

🔄 Sincronização Mesh P2P (3 Nós)

Mantenha seu PC Linux, estação Windows e celular Android sincronizados. Quando um dispositivo desligado é religado, ele recebe automaticamente os deltas atualizados de memória e agenda.

⚙️ Ativação no Boot em 1 Clique

Acesse http://localhost:8790/config ou use ./friday-config --boot on para ativar a inicialização automática no Linux (XDG/systemd) e no Windows (Startup).

🛠️ Auto-Instalador de Dependências

O módulo daemon/auto_deps.py verifica e instala automaticamente pacotes Python, binários de sistema (ffmpeg, grim, curl) e modelos neurais ONNX no primeiro uso.

Instalação Rápida e Automatizada

🐧 Linux (Arch / Ubuntu / Debian / Fedora)

Instala dependências de sistema, ambiente virtual Python, modelos ONNX e inicia o agente:

chmod +x install_linux.sh run.sh
./install_linux.sh
./run.sh

🪟 Windows 10 / 11 (.EXE Autônomo)

Execute o instalador unificado Instalador_Friday_Comercial_Windows.exe ou via script:

install_windows.bat
Friday.bat

📱 Android (.APK + Web PWA)

Instale o pacote android/friday-commercial.apk via ADB ou diretamente no aparelho:

adb install -r android/friday-commercial.apk

🔒 Termo de Uso e Garantia Zero-Data-Retention — Integra Code

Este software é distribuído oficialmente pela Integra Code sob o compromisso absoluto de soberania de dados:

  • Retenção Zero pela Integra Code: A Integra Code NÃO coleta, NÃO armazena, NÃO intercepta e NÃO possui acesso a nenhum áudio, vídeo, captura de tela, banco de dados de memória ou chave de API do usuário.
  • Processamento 100% Local ou Direto com seu Provedor Cloud: Tudo é processado localmente na sua máquina (via Ollama/ONNX/SQLite) ou transmitido diretamente da sua máquina para a API oficial do provedor que você mesmo configurar (Google Gemini, Anthropic Claude ou OpenAI).
  • Auditoria Técnica em Tempo de Execução: O módulo daemon/privacy_guard.py bloqueia qualquer conexão para domínios externos não autorizados e pode ser auditado a qualquer momento com python3 -m daemon.privacy_guard.
